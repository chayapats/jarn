# docs/assets

Static assets embedded in documentation.

## Optional `demo.gif`

**Status (v0.10.0): no demo GIF is tracked.** The main READMEs deliberately do not
embed the missing path, so GitHub/npm previews stay free of broken images.

The demo GIF is generated by running:

```bash
./scripts/record-demo.sh
```

This requires [vhs](https://github.com/charmbracelet/vhs) (`brew install vhs`) and
`gifsicle` (`brew install gifsicle`).  The script runs `demo.tape`, which sets
`JARN_DEMO=1` so the recording is fully deterministic (canned-response provider —
no real API key needed).  Target size: < 3 MB.

After recording, verify the file is below 3 MB, commit it, and then add a Markdown
image named `jarn demo` pointing to `docs/assets/demo.gif` in both `README.md` and
`README-TH.md`.
